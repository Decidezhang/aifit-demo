# AI Fit 小程序（演示版）

本仓库为“AI 智能试衣”小程序的演示代码，示范了使用 TDesign 组件和腾讯云开发能力搭建 AI 试衣体验的基本流程。

> ⚠️ **注意**：此项目仅用于功能演示，不适合作为生产环境直接上线版本。

## 环境准备

- Node.js 16+（建议与本地微信开发者工具保持一致）
- WeChat 开发者工具（含云开发能力）

## 安装依赖

在项目根目录执行：

```bash
npm install
```

该命令会安装 `tdesign-miniprogram` 以及 TypeScript 等开发依赖。

## 小程序端构建 npm 并安装 TDesign

1. 打开微信开发者工具，导入项目根目录。
2. 在工具中打开菜单 `工具 -> 构建 npm` 完成依赖构建。
3. 如果需要更新或补充组件库，可在终端执行：
   ```bash
   npm install tdesign-miniprogram --save
   ```
   然后再次在开发者工具中执行 `构建 npm`，确保 TDesign 组件被正确编译。

## 配置云开发与云函数

1. 在微信开发者工具中开通云开发，选择或创建环境。
2. 根据小程序功能需求创建以下资源：
   - **云函数**：上传本项目中的云函数目录，发布并在控制台中设置相应触发器或环境变量。
   - **数据库集合**：用于存储试衣请求、用户信息、素材等业务数据。
   - **存储桶（Cloud Storage）**：用于存放用户上传的衣服素材、人像数据及生成结果。
3. 在本地 `project.config.json` 中确认云开发环境 ID 与云函数路径配置无误。
4. 发布云函数后，在控制台或本地测试端验证函数是否能正常访问数据库和存储。

## 运行与调试

1. 在终端保证依赖已经安装（`npm install`）。
2. 打开微信开发者工具，选择导入项目。
3. 如果是首次导入或依赖有变动，执行 `构建 npm`。
4. 在工具中开启云开发调试，确保云函数/数据库/存储均指向正确环境。
5. 使用开发者工具的模拟器或真机调试功能体验 AI 试衣流程。
